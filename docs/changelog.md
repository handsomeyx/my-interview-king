## 2026-08-11

### 新增
- **阅读进度持久化**：自动记录每篇文章的阅读位置，首页「继续学习」一键续读
- **学习路径追踪**：首页可视化学习路径图，点圆点切换掌握状态（待学 / 学习中 / 已掌握），实时统计总进度
- **收藏与掌握浮层**：文章页底部浮层，支持收藏、循环切换掌握状态
- **搜索历史与「猜你想搜」**：搜索框空时展示最近搜索与推荐主题，点击直接查询
- **面包屑导航**：文章顶部显示当前位置（首页 › 板块 › 子板块）
- **相关题目**：算法文末自动展示关联 LeetCode 题目（含难度色标），首个示范见「滑动窗口」
- **反馈纠错入口**：文章右下角一键跳 GitHub Issue 并预填页面路径
- **定制 404 页**：中文文案 + 快捷入口
- **阅读进度条 + 返回顶部**：顶部滚动进度、右下返回顶部按钮
- **更新日志页**：本页

### 优化
- **移动端侧边栏**：恢复抽屉式导航（原先被强制隐藏）
- **粒子背景**：移动端与「减少动态效果」模式禁用；标签页隐藏时暂停；修复 `mousemove`/`resize` 监听器跨路由内存泄漏；粒子数按屏幕面积自适应
- **代码块**：开启行号显示
- **Hero 图**：本地化，不再依赖外部 AI 生图 API
- **卡片 hover 动效**：位移与发光降级，尊重 `prefers-reduced-motion`
- **首页数据看板**：移除写死的假数字，改为定性描述

### 修复
- **SPA 路由绑定失效**：图片放大、目录折叠改为事件委托，路由切换后新页面同样生效
- **清理死代码**：移除从未生效的 `enhanceSearch`（其监听的 `.VPNavBarSearchInput` 在 local-search 下不存在）、未使用的 `geometric-*` CSS、未使用的 `watchEffect` 导入

### 后端代码运行器（阶段 1，B 方案）
- **code-exec-service**：Spring Boot 单服务，容器内 `javac` + `java` 跑用户 Java 代码（Process.exec），wall-time 超时（5s）+ 内存上限（-Xmx 256MB）
- **API**：`POST /api/run`（仅 Java，统一响应 `{code,message,data}`，verdict：OK / CE / TLE / RE）
- **前端对接**：CodeRunner 调本机 `localhost:8081`，就地展开编辑器 + 运行 + 输出
- **实施偏离**：原 003 设计用 Judge0 + 微服务，因国内拉 Judge0 大镜像全源失败（digest 错 / EOF / 403 / 502），转 B 方案本地执行。上线流量大时可再走 Judge0 + 容器

# 分布式

> 分布式系统的本质是**多个节点协作完成同一件事**。难点不在"能不能做"，而在**部分失败、网络不可靠、并发时序**这三件事——单机里操作系统帮你兜底，分布式里你得自己面对 CAP、一致性、共识这些概念。

> 🗺️ **可视化学习路径**：查看完整的 [学习路径图](./learning-path.md)，包含全景知识体系、理论线与场景线两条学习路径和跨域关联图。

## 本板块地图

```
distributed/
├── basics（建设中）   ← CAP / Base / 一致性算法（Raft/Paxos）/ 一致性哈希
└── scenarios（招牌）  ← 全链路场景题（接入路由 / 业务逻辑 / 持久化异步）
```

**两条线**：
1. **理论线**（basics）：为什么分布式难——CAP 取舍、Base 最终一致、共识算法怎么让多机对一个值达成一致。
2. **场景线**（scenarios，本站差异化招牌）：把理论落到后端面试高频场景——网关怎么设计、业务逻辑层怎么拆、存储和异步层怎么扛量。

## 怎么学（建议顺序）

**别先啃理论**。CAP/Base 干背没感觉。建议路径：

1. 先看 [scenarios 接入路由](./scenarios/gateway) 或 [持久化异步](./scenarios/storage) 一道场景题，感受"分布式落地要解决什么实际问题"
2. 回到 basics 看理论（CAP 为什么三选二），这时概念有了锚点
3. 再回看场景题里引用的算法（限流 / 一致性哈希 / 缓存），把**后端场景**和**算法板块**串起来——这是本站独有的网状结构

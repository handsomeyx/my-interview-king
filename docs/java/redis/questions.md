# Redis 高频面试题速查

> 15 道高频题，每题"2-4 行可直接答" + 深入链接。配合 [数据结构](./data-structures)、[持久化与缓存问题](./persistence-cache-problems) 深挖页。

## 基础与原理

### Q1：Redis 为什么快？

1. **纯内存**操作（纳秒级）。
2. **单线程**避免锁竞争和上下文切换。
3. **IO 多路复用**（epoll）单线程处理大量连接。
4. **高效数据结构**（SDS、跳表、listpack 等）。

单线程不是"慢"的原因——瓶颈不在 CPU 而在网络 IO 和内存。

### Q2：Redis 是单线程吗？

**不是**了。Redis 6.0 引入**多线程网络 IO**（接收 / 发送数据多线程，命令执行仍单线程）。准确说：**命令执行单线程，网络 IO 可多线程**。

### Q3：缓存淘汰策略有哪些？

8 种：
- `noeviction`：不淘汰，写报错（默认）。
- `allkeys-lru` / `volatile-lru`：所有 key / 设了过期的 key 里 LRU。
- `allkeys-lfu` / `volatile-lfu`：LFU（按频率）。
- `allkeys-random` / `volatile-random`：随机。
- `volatile-ttl`：优先淘汰快过期的。

**选型**：纯缓存用 `allkeys-lru`（或 lfu）；有持久数据混存用 `volatile-lru`。

## 持久化与缓存（深入见专题页）

### Q4：RDB vs AOF 怎么选？

缓存用 RDB；重要数据 AOF everysec；主流混合持久化。详见 [持久化与缓存问题 Q1](./persistence-cache-problems)。

### Q5：缓存穿透 / 击穿 / 雪崩区别？

- 穿透：查**不存在**的 → 布隆过滤器 / 空值缓存。
- 击穿：**单热点 key** 过期 → 互斥锁。
- 雪崩：**大量 key** 同时过期或 Redis 挂 → TTL 随机 + 高可用。

详见 [持久化与缓存问题 Q2-Q4](./persistence-cache-problems)。

### Q6：缓存一致性写顺序？

**先更 DB 再删缓存**（不是先删）。详见 [持久化与缓存问题 Q5](./persistence-cache-problems)。

## 高可用架构

### Q7：主从复制原理？

1. 从库初次全量同步：主库 bgsave 生成 RDB 发给从库，从库加载。
2. 之后增量：主库把写命令实时同步到从库（基于 repl-backlog）。

主写从读，读写分离。

### Q8：哨兵（Sentinel）干嘛？

监控主从、**主挂了自动选新主**（故障转移）、通知客户端。解决"主节点单点"问题。哨兵本身不承载数据流量，只做监控选举。

### Q9：集群（Cluster）和哨兵区别？

- 哨兵：1 主多从 + 哨兵监控，**主从切换**，数据**全量**在每个节点。
- 集群：数据**分片**（16384 槽，每节点管一部分），无中心、节点间 gossip。

**选型**：数据量小用哨兵；数据量大（单机存不下）用集群。

## 实战问题

### Q10：大 key 怎么处理？

单个 key 的 value 太大（如 List 10 万元素）。危害：读写阻塞、网络拥塞、删除时阻塞（`del` 大 key 是同步操作）。
- 拆成小 key。
- 删除用 `UNLINK`（异步删除，4.0+）。
- 监控 `redis-cli --bigkeys`。

### Q11：热 key 怎么处理？

某个 key 访问量极大（QPS 数万），单节点成瓶颈。
- 本地缓存（多级缓存）拦截。
- 多副本（同一热 key 复制多份，打到不同节点）。

### Q12：Redis 事务（MULTI/EXEC）支持回滚吗？

**不支持**。事务中某条命令运行时出错，不回滚，后续继续执行。**和 MySQL 事务完全不同**。
Redis 事务本质是"批量打包命令"，原子性弱。要原子 + 条件判断用 **Lua 脚本**。

### Q13：过期策略？

- **惰性删除**：访问时检查过期才删（可能堆积）。
- **定期删除**：周期性抽样删过期 key。

两者结合。被删前内存满了走淘汰策略（Q3）。

### Q14：pipeline 和 Lua 区别？

- **pipeline**：打包多条命令一次发送，**减少网络 RTT**。不保证原子（命令间可能穿插别的）。
- **Lua**：脚本内多条命令**原子执行**（命令执行单线程，脚本内不会被插）。

**取舍**：纯批量用 pipeline；要原子用 Lua。

### Q15：数据类型怎么选？

5 种基础类型 + 场景：String 计数 / 缓存对象、List 队列、Hash 对象、Set 去重、Zset 排行榜。底层编码见 [数据结构](./data-structures)。

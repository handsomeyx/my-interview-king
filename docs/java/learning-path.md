## 推荐学习顺序

1. **入门阶段**：`Java 基础` → `集合框架` → `Java 并发` → `JVM`
2. **进阶阶段**：`Spring IoC/AOP` → `Spring 事务` → `MyBatis`
3. **深入阶段**：`MySQL` → `Redis` → `Kafka`
4. **实战阶段**：结合[算法学习路径](/algorithm/learning-path)中的系统算法，理解 Java 生态中各组件的底层原理

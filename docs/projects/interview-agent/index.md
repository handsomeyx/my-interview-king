# 智能面试助手项目实战

一个面向小白的 LangChain Agent 实战项目，仅需填写 API Key 即可使用，1 天内就能跑通。

> 🗺️ **可视化学习路径**：查看完整的 [学习路径图](../learning-path.md)，包含项目全景、三阶段开发路线和跨域知识关联。

## 项目亮点

- **小白零门槛**：仅需填写 API Key，一键启动，无复杂配置
- **知识点全覆盖**：完整覆盖 Agent、MCP、Skill 三大核心知识点
- **可扩展性强**：小白可轻松写新技能，扩展 Agent 能力
- **贴合面试场景**：与「我是面试大王」知识库完美契合，用户可直接用它刷面试题

## 项目结构

```
interview-agent/
├── agent/              # Agent 核心实现
│   └── interview_agent.py  # 面试助手 Agent
├── mcp/                # MCP 协议实现
│   └── mcp_client.py    # MCP 客户端
├── skills/             # Skill 技能开发
│   ├── base_skill.py     # 技能基类
│   ├── interview_skill.py  # 面试题解答技能
│   └── plan_skill.py     # 学习计划生成技能
├── config.py           # 配置文件（填写 API Key）
├── main.py             # 项目入口
├── requirements.txt    # 依赖文件
└── README.md           # 项目说明文档
```

## 学习路径

1. **环境搭建**：10 分钟搞定环境配置
2. **Agent 基础**：了解 Agent 核心概念和实现
3. **MCP 协议**：学习标准化通信协议
4. **Skill 开发**：掌握自定义技能开发
5. **项目运行**：一键启动，开始使用
6. **扩展教程**：学习如何扩展新技能

## 适合人群

- **编程小白**：想了解 AI Agent 技术的初学者
- **面试备考者**：需要刷面试题的求职者
- **技术爱好者**：对 LangChain 和大模型应用感兴趣的开发者

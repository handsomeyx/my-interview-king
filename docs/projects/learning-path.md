## 推荐学习顺序

1. **入门阶段**：按环境搭建 → Agent 基础 → MCP 协议 → Skill 开发的顺序，从零跑通项目
2. **进阶阶段**：深入理解 MCP 协议规范，学习 Skill 的编排逻辑和执行引擎
3. **实战阶段**：独立完成一个自定义 Skill 或接入一个新的 MCP Server
4. **扩展阶段**：参与项目的扩展开发，为面试助手添加新的能力模块

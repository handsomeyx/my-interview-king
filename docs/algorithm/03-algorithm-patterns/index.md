# 算法模式

算法套路是解决问题的算法模式，掌握常见的算法套路对于快速解决问题至关重要。本章节将介绍常见的算法套路，包括搜索、动态规划、优化和数学逻辑等。

## 目录

- [搜索](search/)
- [动态规划](dynamic-programming/)
- [优化](optimization/)
- [数学逻辑](math-logic/)

## 学习目标

1. **掌握搜索算法**：理解二分搜索、DFS/BFS、回溯等搜索算法的原理和应用
2. **理解动态规划**：掌握动态规划的基本思想和常见类型（背包、区间、状态机）
3. **熟悉优化算法**：了解贪心、双指针、滑动窗口、单调栈等优化算法
4. **掌握数学逻辑**：理解位运算、大数运算、概率算法等数学逻辑

## 学习建议

- **理解原理**：深入理解每种算法的核心思想和原理
- **多做练习**：通过实际问题练习，巩固所学算法
- **总结归纳**：总结算法的适用场景和解题模板
- **灵活应用**：根据具体问题，选择合适的算法

通过本章节的学习，你将掌握常见的算法套路，为解决复杂问题提供有力的工具。

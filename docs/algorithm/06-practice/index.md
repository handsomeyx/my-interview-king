# 专项练习（框架→习题）

> 配套 [算法框架](../00-algorithm-frameworks/)。每篇专项练习针对**一个框架**，5-10 道题让你套到肌肉记忆。这是 labuladong「框架思维」能落地的关键——学完框架立刻刷同类题。

## 为什么这么组织

`05-top-interview-100` 是**按题型**（数组/链表）组织的，但学与练脱节：读完滑动窗口框架，想练手却要翻数组分组里挑题。

本板块把题**按框架重新组织**：滑动窗口框架 → 滑动窗口专项 10 题；二分查找框架 → 二分专项 10 题。**学与练一一对应**，形成肌肉记忆。

## 学习路径

1. **先读框架**：理解模板（[00-algorithm-frameworks](../00-algorithm-frameworks/)）
2. **立刻做专项**：套同一个模板做 5-10 题
3. **回看框架**：做完再读框架，巩固「三处钩子」（收缩条件 / 更新位置 / 结果定义）

## 每篇结构

- 点名套哪个框架 + 框架速记
- 题目清单（题号 + 难度 + 「框架哪步变化」）
- 3 道例题完整示范（基础 / 进阶 / 变式）
- 练习建议（先做哪些、压轴题）

> 想先体验完整闭环，直接进 [滑动窗口专项练习](./sliding-window-practice)。

# 算法框架学习

## 思考锚点

算法题的困难之处往往不是「写不出代码」，而是「不知道从哪里开始想」。当你看到一道新题，如果脑子里没有任何解题思路，很容易卡壳半小时。

算法框架的价值就在于此：它给你一个**思考的起点**。比如看到「求最值」想到动态规划，看到「有序数组查找」想到二分，看到「树的遍历」想到 DFS/BFS。框架不是万能的——它需要你根据具体题目调整细节——但它能让你从「无从下手」变为「有方向可循」。

掌握框架的正确方式是：**先用框架模板解决经典题，再尝试不看模板重新写，最后用自己的话解释每一步的决策依据**。

## 为什么要学习算法框架？

对于编程基础较弱的小白来说，直接上手做算法题可能会感到无从下手。算法框架就像是解题的模板，帮助你：

1. **建立解题思路**：掌握框架后，遇到类似问题时能快速想到解决方案
2. **提高代码质量**：框架提供了规范的代码结构，避免逻辑混乱
3. **节省思考时间**：不需要每次都从头开始设计算法
4. **理解算法本质**：通过框架理解算法的核心思想

## 如何使用这些框架？

1. **理解原理**：先阅读框架的原理讲解，理解算法的核心思想
2. **记住模板**：熟悉代码模板，知道每个部分的作用
3. **做练习题**：在高频真题练习章节中找到对应的题目进行练习
4. **灵活应用**：根据具体问题调整框架，适应不同场景

通过系统学习这些框架，你将能够更自信地面对各种算法问题，逐步提高解题能力。

## 使用示例

### 示例：两数之和

#### 1. 问题描述

**题目**：两数之和

**来源**：LeetCode 1

**难度**：简单

**题目描述**：
```
给定一个整数数组 nums 和一个目标值 target，请你在该数组中找出和为目标值的那两个整数，并返回它们的数组下标。
你可以假设每种输入只会对应一个答案。但是，数组中同一个元素不能使用两遍。
```

#### 2. 我的解法

**思路**：
使用哈希表来存储已经遍历过的元素及其下标，对于当前元素，检查 target - 当前元素是否在哈希表中。

**代码**：
```python
def twoSum(nums, target):
    hash_map = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in hash_map:
            return [hash_map[complement], i]
        hash_map[num] = i
    return []
```

**时间复杂度**：O(n)
**空间复杂度**：O(n)

#### 3. 费曼讲解

**讲解对象**：假设是一个没有算法背景的人

**讲解内容**：
想象你有一个任务，要在一堆数字中找到两个数，它们加起来等于一个目标值。比如，数组是 [2, 7, 11, 15]，目标值是 9。

我们可以一个一个地看这些数字。首先看第一个数字 2，我们需要找一个数是 9-2=7。但我们还没有看过其他数字，所以先把 2 记下来。然后看第二个数字 7，我们需要找 9-7=2，哎，我们之前记过 2，所以这两个数就是 2 和 7，它们的下标是 0 和 1。

为了高效地记住我们看过的数字，我们可以用一个哈希表，就像一个字典，把数字作为键，下标作为值。这样当我们需要找一个数时，只需要查一下字典就知道它在不在里面了。

**示例**：
输入：nums = [2, 7, 11, 15], target = 9

1. 遍历到 2，complement = 9-2=7，哈希表为空，将 2:0 存入哈希表
2. 遍历到 7，complement = 9-7=2，在哈希表中找到 2，返回 [0, 1]

#### 4. 逻辑漏洞分析

**漏洞发现**：
- 如果数组中有重复元素，比如 nums = [3, 3], target = 6，是否会有问题？
- 如果没有找到答案，函数返回空数组，是否符合题目要求？

**解决方案**：
- 对于重复元素，当遍历到第二个 3 时，complement = 6-3=3，此时哈希表中已经有第一个 3，所以会返回 [0, 1]，正确。
- 题目保证每种输入只会对应一个答案，所以不需要处理没有答案的情况。

**测试用例**：
- 输入：nums = [3, 3], target = 6，输出：[0, 1]
- 输入：nums = [2, 5, 5, 11], target = 10，输出：[1, 2]

#### 5. 优化思路

**当前解法的局限性**：
- 空间复杂度为 O(n)，需要额外的哈希表空间

**可能的优化方向**：
- 如果数组是有序的，可以使用双指针法，空间复杂度为 O(1)

**优化后的解法**：
```python
def twoSum(nums, target):
    # 先排序
    sorted_nums = sorted(enumerate(nums), key=lambda x: x[1])
    left, right = 0, len(sorted_nums) - 1
    while left < right:
        current_sum = sorted_nums[left][1] + sorted_nums[right][1]
        if current_sum == target:
            return [sorted_nums[left][0], sorted_nums[right][0]]
        elif current_sum < target:
            left += 1
        else:
            right -= 1
    return []
```

- 四数之和：找出四个数之和为目标值

**解题思路对比**：

- 三数之和：排序后使用双指针，固定一个数，找另外两个数
- 四数之和：类似三数之和，固定两个数，找另外两个数
- 两数之和 II：直接使用双指针，因为数组是有序的

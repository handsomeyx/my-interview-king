# 算法方法论

算法方法论是编程的核心，掌握好算法思想和方法论，对于解决复杂问题至关重要。本章节将介绍算法学习的方法论，包括费曼技巧、时空复杂度分析和工程化编码习惯。

## 目录

- [用费曼技巧记录逻辑漏洞的模板](feynman-template.md)
- [时空复杂度分析深度指南](complexity-guide.md)
- [工程化编码习惯](coding-habits.md)

## 学习目标

1. **掌握费曼技巧**：通过讲解来加深对算法的理解，发现并修复逻辑漏洞
2. **理解时空复杂度**：学会分析算法的时间和空间复杂度，选择最优解决方案
3. **培养工程化编码习惯**：养成良好的变量命名、边界检查等编码习惯，提高代码质量

## 学习建议

- **循序渐进**：从基础的算法思想开始，逐步深入到复杂的算法设计
- **多做练习**：通过实际编码练习，巩固所学知识
- **总结归纳**：定期总结算法思想和解题技巧，形成自己的知识体系
- **交流分享**：与他人交流算法学习心得，拓宽思路

通过本章节的学习，你将掌握算法学习的基本方法论，为后续的算法学习打下坚实的基础。

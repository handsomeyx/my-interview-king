# AI Agent 核心知识库

## 知识库简介

本知识库是一个全面的 AI Agent 学习资源，涵盖了从基础概念到高级应用的各个方面。它旨在帮助开发者、研究人员和学生快速掌握 AI Agent 的核心原理、技术栈和实践方法。

## 学习路线

### 1. 基础入门（00-basics）
- **LLM 核心原理**：了解 Transformer 架构、注意力机制和 Prompt 工程
- **Agent 定义与核心组件**：掌握 Agent 的基本概念、核心组件和发展历史
- **MCP 协议基础**：理解模型上下文协议和多模态协作
- **技能体系概述**：了解 Agent 的技能体系和评估方法

### 2. 底层底座（01-llm）
- **模型架构**：学习 GPT、LLaMA、Qwen 等主流模型的架构
- **Prompt 工程**：掌握 Agent 提示词设计、Few-Shot 和 Chain-of-Thought 等技术
- **模型微调**：了解 LoRA、QLoRA 和 Agent 专属微调方法
- **RAG 检索增强**：掌握 Agent 知识注入的核心技术
- **LLM 运维**：学习模型部署、推理优化和监控方法

### 3. 核心本体（02-agent）
- **Agent 架构**：学习 ReAct、Plan-and-Execute、Reflexion 等架构
- **核心组件**：深入了解 Agent 的感知、规划、记忆和工具调用组件
- **多 Agent 系统**：掌握多 Agent 协作、通信和冲突解决方法
- **Agent 评估**：学习 Agent 效果、安全和鲁棒性的评估方法
- **Agent 安全**：了解 Prompt 注入、幻觉和权限控制等安全问题

### 4. 通信协议（03-mcp）
- **MCP 协议**：深入理解 MCP 协议的原理、标准和实现
- **上下文管理**：掌握长上下文、上下文压缩和记忆管理技术
- **多模态 Agent**：学习图文、语音、视频协作的多模态 Agent
- **Agent 通信**：了解消息队列、RPC 和共享内存等通信方式

### 5. 技能能力（04-skills）
- **工具调用**：掌握 Function Call、API 集成和插件开发
- **规划能力**：学习思维链、树状搜索和强化学习规划
- **记忆系统**：了解短期记忆、长期记忆和向量数据库
- **推理能力**：掌握逻辑推理、数学推理和常识推理
- **领域技能**：学习代码 Agent、数据 Agent、运维 Agent 等领域技能

### 6. 工程落地（05-engineering）
- **实战项目**：学习 AI 客服、代码助手、自动化运维 Agent 等项目
- **Agent 框架**：了解 LangChain、AutoGPT、MetaGPT、Dify 等框架
- **部署运维**：掌握 Docker、K8s、云原生和监控告警
- **性能调优**：学习 Agent 响应速度、并发和资源占用优化
- **最佳实践**：了解代码规范、测试和 CI/CD 等工程最佳实践

### 7. 面试求职（06-interview）
- **面试题汇总**：掌握基础、原理、工程和场景题
- **项目经验**：学习如何写简历和如何讲项目
- **面试指南**：了解面经、薪资和岗位要求
- **简历模板**：使用 Agent 工程师专属简历模板

## 使用说明

1. **按顺序学习**：建议按照学习路线的顺序进行学习，从基础入门开始，逐步深入到高级主题
2. **实践为主**：每个主题都包含实践示例，建议动手实现以加深理解
3. **参考资料**：每个章节都提供了相关的参考资料和进一步学习的资源
4. **社区贡献**：欢迎通过 GitHub 提交 issue 和 PR，共同完善知识库

## 贡献指南

1. **内容贡献**：可以提交新的章节、更新现有内容或修复错误
2. **格式规范**：遵循 Markdown 格式规范，确保内容清晰易读
3. **代码示例**：提供的代码示例应保持简洁明了，并有适当的注释
4. **参考引用**：引用外部资源时应注明来源

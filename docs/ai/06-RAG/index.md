# 实战环节：
1.RAG中的检索模块召回错误结果时，你会如何处理？
<details>
<summary>点击查看答案</summary>
答：首先我们需要对错误进行分类，看是语义不匹配、信息过时还是噪声的原因。然后针对性的去解决。然后对召回阶段进行优化：

- 采用多路召回：设计多检索架构。
- 进行向量质量优化：选更适配的模型，做更精细的分块和清洗。
- 召回数量和阈值控制：设置相似度阈值，避免低质量结果混入。

召回后排序阶段进行优化，在粗排后加入轻量的排序模块。

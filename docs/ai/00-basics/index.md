# 基础入门

## 思考锚点

AI Agent 与传统 AI 的核心区别是什么？一句话总结：**传统 AI 是「被动回答」，Agent 是「主动执行」**。

传统 AI 像一个知识渊博但被动的顾问——你问它什么，它回答什么，不会主动帮你做事。而 Agent 像一个「有自主能力的助手」——你只需要告诉它目标（比如「帮我规划去厦门的旅行」），它会自己拆任务、调用工具、执行步骤、甚至根据情况调整方案。

这个区别来自 Agent 的三个核心能力：**规划能力**（把大任务拆成小步骤）、**工具调用能力**（不只是聊天，还能操作外部世界）、**记忆能力**（记住之前的交互上下文）。

理解了这个区别，后面学习 Agent 的架构和组件时就有了清晰的锚点。

如果你是刚接触 AI Agent 的小白，不知道从哪里开始学习，可以先看看我在这章节的知识梳理，详细看完你会对Agent有个总体的认知。在我面试的数多小厂中，基本上也只拷问大家"是什么"的层面，看完这个章节，相信大家基本上能面对部分小厂的认识。


## 什么是AI Agent?
可千万别觉得Agent多么高深，它其实就死一个**有自主能力的智能助手**，它像人一样，理解你的需求、思考如何解决、主动去执行任务，不需要你一步步手把手指挥。

如何区分AI和AIAgent呢？拿个例子来解释会比较清楚：

比如，你想让助手帮你规划一场去厦门的旅行，普通的**AI**可能会就给你推荐鼓浪屿，十里长堤等景点。但是AI Agent会这样做：
- **理解你的需求**，确定你是不是喜欢自然风光，还是娱乐场所，预算多少，车程多少
- **主动思考**符合你的需求的景点，对比交通、住宿、门票
- 执行查实时路况，预定门票等任务
- 如果发现某个景点人流很大，会告诉你，给你备选方案。

简单来说，AI就是**“你问我答”**，Agent就是**”你说目标，我来搞定**。

## Agent怎么思考的？

核心就是**LLM**（大预言模型），你可以认为它就是Agent的大脑，Agent的所有智能行为，都依赖这个脑子完成。

那LLM是什么呢？你可以把它想象成一个读了全世界书的超级学霸，**能听懂、能说话、能简单思考**的超级大脑。在生活中我们常使用的GPT，国产的通义千问，都是常见的LLM。而LLM最核心的的能力，决定了Agent的智能水平：
- **自然语言理解能力**：比如我说帮我订一张明天去厦门的机票，他能理解"时间“，”目的地“，”任务“
- **自然语言生成能力**：能生成符合人类语言习惯的文字，可以和你聊天
- **逻辑推理能力**：能进行简单的逻辑思考能力，A比B高，B比C高。这是Agent能自主规划的核心。

看到这，你是不是觉得诶LLM什么都能做，其实它有两个明显的缺点。
-**会说胡话（幻觉）**：比如你问它2025年春节是哪一天“，它可能给你一个错误的日期——因为它知识是训练到某个时间点的，且可能记错信息。
- **不会动手**：LLM 只能生成文字，不能直接调用工具（比如不能直接帮你订高铁票、查天气），需要 AI Agent 来“帮它动手”。

## AI Agent的通信规则”：MCP协议基础

MCP的全称是 Model Context Protocol（模型上下文协议），你不用记复杂的定义，只需要理解它的核心作用：**规范AI Agent之间、AI Agent与LLM之间的“沟通方式”，让它们能“互相听懂”。

比如两个人沟通，一个说中文，一个说英文，就无法听懂对方；但是两个人都讲普通话，就能顺利沟通。MCP就是AI世界里的“普通话”。

作为基础知识，你不用深入协议的技术细节，你只需知道它的两个核心作用：
- **规范上下文传递**：Agent 会把“用户需求、之前的执行结果”等信息，按照 MCP 协议的规则，传递给 LLM，让 LLM 能“记住”之前的内容。（比如你之前告诉 Agent 预算500元，LLM 能通过 MCP 协议拿到这个信息）
- **规范多主体写作**：多个 Agent 协同工作时，用 MCP 协议定义“谁来做什么、做完后传递什么信息”，避免混乱。（比如一个 Agent 负责查天气，做完后用 MCP 协议把天气信息传递给负责规划行程的 Agent）

### 补充：多模态协作：
MCP 协议不仅支持“文字沟通”，还支持多模态协作——比如 Agent 能传递图片、语音、视频信息，让 LLM 或其他 Agent 理解。

## Skill概述

如果说 LLM 是 AI Agent 的“大脑”，MCP 是“沟通规则”，那么“Skill“就是Agent 的“武器库”——Agent 靠这些技能，完成各种实际任务。

Agetn有五个核心技能，先带大家了解每个技能对应的应用场景：

-**工具调用技能**：Agent能调用外部工具完成任务，比如查天气就调用天气API，操纵Excel就调用办公工具，这是Agent能动手的核心。
- **规划技能**：Agent能根据用户需求，制定详细的执行计划，比如你让他规划旅行，它能制定“查景点-订交通等步骤，还能调整计划。
-**记忆技能**：Agent 能记住之前的交互内容，比如你上次让它帮你订过一次美式咖啡，下次它会自动记住你的喜好——分为**短期记忆**如当前对话内容）和**长期记忆**如你的喜好、历史任务）。
- **推理技能**：Agent 能进行逻辑推理，解决复杂问题，比如你让它帮你解决“如何在预算500元内，完成周末旅行”
- **领域技能**：Agent 能针对某个具体领域，拥有专属技能，比如“代码Agent”会写代码、查bug；“客服Agent”会解答用户问题、处理投诉；“运维Agent”会监控服务器、处理故障。

到这里我们可以简单总结一下，Skill与LLM、MCP的关系。LLM思考做什么、怎么做；Skill执行具体操作；MCp负责中间沟通，三者协同。

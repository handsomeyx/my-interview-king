# 内容生成规则（去 AI 味）

> 触发：`CLAUDE.md` 红线④。**任何"生成文章内容"前必读，生成后必过验收清单。**
> 适用：写新文章、改写/扩写已有文章、生成章节或段落、写教程/讲解类 markdown。
> 不适用：代码、配置、纯目录页、表格数据、内部文档（需求变更/规则本身）。

## 为什么要这份规则

AI 生成的中文技术文章有固定的"味道"：**太对称、太干净、爱升华、不犯错**。有经验的读者一眼能看出来。本规则把"AI 味"的具体来源列成清单，生成前后逐条自检。"去 AI 味"本身是个模糊指令，AI 不靠具体清单是做不好的——所以这份规则必须**严格执行，不是参考**。

## 生成前：先定三件事（定不清就别动笔）

- [ ] 这篇的**核心洞察**是什么？（一句话能说清；说不清=还没想好，不要动笔）
- [ ] 哪些是**必须保留的事实/代码/结构**？（生成/改写时不得破坏）
- [ ] **读者画像**是谁？（决定深浅与节奏）

## 生成时：AI 味黑名单（禁用）

- [ ] **空口承诺**：禁"刷完就掌握""读完你就能…""肌肉记忆成型"这类不传递信息的升华。**开头尤其要查。**
- [ ] **结尾升华 + 署名**：禁"这就是 X 说的…""正如 Y 所言…"。**正文不给竞品/他人署名凑分量**；结尾不写读后感式总结。
- [ ] **过度对称**：不要让每个章节/例题长成同一个模子（同长度、同结构）。关键章节用"先讲为什么"打破节奏。
- [ ] **冗余双陈述**：不要"陈述一遍 + 换词总结一遍"。一件事说一次。
- [ ] **没有错误 / 踩坑 / 第一人称**：**每篇至少 1 个具体易错点或常见错法**。AI 不犯错、人犯错——这是 AI 味的根，也是最有效的去味手段。
- [ ] **万能废话**：易错点/建议必须具体，禁"注意边界条件""小心特殊情况""根据实际调整"这类放之四海皆准的空话。
- [ ] **Platitude**：删掉听起来权威但信息量为零的句子（"X 是 Y 的标配优化""至关重要""不言而喻"）。
- [ ] **建议的形状 ≠ 建议本身**：推荐要有**取舍和理由**（例："只做 3 道选 1/3/7，因为覆盖三种不同语义"），不要只做"基础/进阶/压轴"分组。
- [ ] **过度承诺范围**：题数/覆盖范围要诚实。精讲 3 道就说 3 道，不要暗示 10 道全精讲。

## 生成后：验收清单（逐条过，任一 No 就回去改）

- [ ] 开头有没有空口承诺？（有 → 删）
- [ ] 结尾是不是升华/读后感/署名？（是 → 删或换成具体下一步指引）
- [ ] 全篇有没有至少 1 个**具体**易错点？（没有 → 补；是万能废话 → 改具体）
- [ ] 有没有 platitude？（有 → 删或换成具体含义）
- [ ] 有没有"陈述 + 重述"的冗余双段？（有 → 合并）
- [ ] 章节/例题是不是全对称？（是 → 打破一处节奏，比如某段先讲"为什么"）
- [ ] 推荐或建议有没有取舍和理由？（没有 → 补）
- [ ] 范围/数量表述是否诚实？（不 → 改）
- [ ] （改写时）该保留的事实/代码是否原样保留？（必查）

## 反面教材（来自真实评审，作为负面样例）

以下句子都出自一篇被判定"AI 味重"的文章：

- ❌ "刷完这 10 题，滑动窗口的肌肉记忆就成型了。" → **空口承诺**
- ❌ "这就是 labuladong 说的'套框架套到肌肉记忆'。" → **结尾升华 + 竞品署名**
- ❌ "单调队列是滑动窗口求极值的标配优化。" → **platitude**，删掉信息量不减
- ❌ "先打基础…再进阶…压轴…" → **建议的形状**，不是建议本身
- ❌ "注意边界条件。" → **万能废话**，等于什么都没说

## 练习文（06-practice 类）额外复查

写「框架→习题」专项练习文（`06-practice/`）时，除上述通用清单外，**额外对照 007**（007 是首篇产出去味案例，是练习文的去味基线）：

- [ ] **题数诚实**：明确「精讲 N 道 + M 道清单」，不暗示全精讲
- [ ] **每道精讲例题 ≥ 1 个具体易错点**（非万能废话，要写到具体的符号 / 顺序 / 边界，如 `> 1` 不是 `>= 1`、`<=` 不是 `<`）
- [ ] **练习建议含取舍型推荐**（如「只做 3 道选 X/Y/Z，理由是覆盖三种语义」），不只「基础/进阶/压轴」分组
- [ ] **关键例题用「先讲为什么」打破对称**（如单调队列题先讲为什么暴力超时、必须换结构）
- [ ] **「如何套框架」+「关键变化点」合并一段**，不双陈述
- [ ] **结尾不升华、不署名竞品**，换具体下一步指引
- [ ] **题目清单不重复占位**（每行一道真题，不偷懒用同一道题占两行）

练习文红线（不得动）：
- [ ] 框架速记伪代码、题目清单表格、Java 代码逻辑、对比例题段
- [ ] 不新增/删除例题，不改题目清单的题（除非清单本身有 bug 如重复占位）

## 一句话原则

**有取舍、有错误、有具体；没升华、没废话、没对称。**
